# Commercial licensing

The OpenNPU hardware design is published under
[CERN-OHL-S-2.0](LICENSES/CERN-OHL-S-2.0.txt), a strongly reciprocal
open-hardware licence. In short: if you make and distribute a product
that contains this design, or a design derived from it, you must publish
the complete source of that product's design under the same licence.

That is fine for hobby, research, education and open products.

If you want to use the design in a **closed product**, without
publishing your own design, you need a separate commercial license from
the author. Typical cases:

- an FPGA bitstream based on this RTL shipped inside a commercial device;
- an ASIC or FPGA IP block derived from this RTL;
- integration of the accelerator into proprietary hardware.

Contact the author through GitHub ([@manvalan](https://github.com/manvalan))
by opening an issue titled "Commercial license", or privately at the
address shown on the GitHub profile.

The software tools (MIT) and documentation (CC BY 4.0) need no
commercial license; just keep the copyright notices.
