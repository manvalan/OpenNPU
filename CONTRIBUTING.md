# Contributing

Thanks for your interest. Issues, questions, test reports and ideas are
very welcome.

## How this repository works

This public repository is generated automatically from the author's
private working repository. Pull requests cannot be merged directly here:
an accepted change is applied in the private repository and comes back
on the next sync, with credit to you in the commit message.

2. it is licensed under the licence of the files it changes; and
3. you grant the author a perpetual, worldwide, royalty-free right to
   use, modify and relicense your contribution, including under

Please add this line to each commit (`git commit -s` does it for you):

    Signed-off-by: Your Name <your@email>

## Reporting results

If you run the design or the benchmarks on your own hardware, open an
issue with the board, the clock, the command used and the output. The
project only publishes measured numbers, so your measurements are
valuable.
